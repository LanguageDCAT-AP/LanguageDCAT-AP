LanguageDCAT-AP

LanguageDCAT-AP is an application profile initiated in the context of the Common European Language Data Space and aiming to cover the exchange of language data, language models and language technologies among catalogues.

Current official versions:

To cater for different needs of language providers and consumers, there are currently two official versions:

  • release 0.9.3 focuses on metadata properties required mainly for discoverability purposes
  • release 0.9.5 (based on v0.9.3) supports the description of synthetic datasets and allows for a richer description of models (e.g., covering deployment aspects).

Structure of the repository

/releases: LanguageDCAT-AP releases (0.9.1, 0.9.2, etc.).
